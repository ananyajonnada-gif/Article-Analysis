# 📊 Programming Articles Exploratory Data Analysis (Learning Project)

This repository contains my implementation of a **Programming Articles Exploratory Data Analysis (EDA)** project. I recreated this project as a learning exercise by following an existing tutorial to improve my understanding of Python, data analysis, and interactive visualizations.

During the project, I also explored the dataset further by grouping programming tags into broader categories and creating additional interactive visualizations using Plotly.

---

## 🚀 Project Overview

This project explores a dataset of programming-related articles to understand patterns and trends in programming topics through interactive visualizations.

Some of the questions explored include:

- Which programming topics appear most frequently?
- How are articles distributed across different domains?
- What are the major programming categories?
- Which technologies dominate the dataset?

---

## 📂 Dataset

The dataset used in this project is loaded directly from an online source using a URL within the notebook. Therefore, no local dataset file is included in this repository.
